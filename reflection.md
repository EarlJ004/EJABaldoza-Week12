Reflection:

Throughout Weeks 7 to 11, I designed my programs to gradually build my understanding of Dart programming concepts, starting from basic variables and data types to object-oriented and asynchronous programming. 
In Week 7, I used variables, operators, and output statements to represent and process simple purchasing information. 
In Week 8, I added user input, conditional statements, loops, functions, and error handling to create a more interactive and reliable program. 
For Weeks 9 and 10, I developed a jeepney transportation system because it is a practical and familiar real-world scenario that allowed me to apply object-oriented programming concepts such as classes, constructors, encapsulation, inheritance, polymorphism, abstraction, and mixins. I organized the code into separate classes and methods to improve readability, maintainability, and code reusability. 
In Week 11, I enhanced the application by implementing asynchronous programming with Future, async, and await to simulate saving records without interrupting program execution. I also included comments throughout the code to clearly explain the purpose of each class, constructor, and method for easier understanding during code review. 
Overall, my design choices focused on creating structured, realistic, and scalable programs while demonstrating the progressive application of Dart programming concepts learned throughout the course.
